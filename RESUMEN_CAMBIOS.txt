🚀 CÓMO EMPEZAR
================================================================================

1. INSTALAR DEPENDENCIAS
   $ npm install

2. INICIAR EN DESARROLLO
   $ npm run dev

3. ABRIR EN NAVEGADOR
   Visita: http://localhost:3000

4. PROBAR MODO OSCURO
   Haz clic en el botón circular en esquina superior derecha
   - Icono Luna (sol) = cambiar a oscuro
   - Icono Sol = cambiar a claro

5. COMPILAR PARA PRODUCCIÓN
   $ npm run build
   $ npm start
